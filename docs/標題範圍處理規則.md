# 標題範圍處理規則

2026-09-04 老師定案。寫程式只准挑選目標法：有這把鑰匙，就做這件事。禁止先黏成一串再削（消去法）。禁止「沒 A 就 B」。

組字串只准走 FeatureTimeline.combinePackRangeLabel。禁止各檔自己 join 分號、自己加中括號、自己再寫一套融合。獨立考試、錄音 Snapshot、material_refs 摘要，同一把。FeatureTimeline 不在＝回空，不准退回舊 join。

相關雷區：.cursor/rules/title-range-label-invariant.mdc  
組合面板欄位與套餐定義：`docs/組合作業範圍與套餐.md`、`.cursor/rules/combo-homework-pack-invariant.mdc`

## 誰寫什麼

- 大標題（組合層組標題）＝套餐名。空白才帶入。不准黏活頁名。
- 小標題（錄音／考試）＝套餐名＋範圍。活頁別名只給區段欄，不准進標題。
- 區段欄＝活頁別名（`pickPackSheetLabel`）。沒改過的別名就是活頁名（欄位值）。

## 挑選（進匣之前）

有起、有迄、有套餐名 → 這列進匣。
課本列：有主單元／次單元／標題／大題／次題／小題任一層 → 用 `套餐名`＋空格＋`主單元 / 次單元 / 標題 / 大題 / 次題 / 小題` 組字，仍只走 combinePackRangeLabel。
同一列有頁碼或題號 → 進對應模式。
從 material_refs 進來時：有 range_spec → 解析成區間再進匣。

## 匣

兩個維度，互不干涉：
1. 來源套餐（combo_id；沒有 id 才用套餐名）
2. 該套餐內再分頁碼匣、題號匣
不同匣的區間不准互融。同一套餐多本活頁的頁碼進同一個頁碼匣。

## 匣內：排序、融合、前綴

1. 排序：起點由小到大。
2. 融合：下一筆起點小於或等於目前迄加 1 就收成一筆（相連、重疊都融）。對不上＝斷層，維持兩筆。
3. 前綴（不要中括號）：
   - 頁碼：只一段且單頁 → p. 1；有區間或斷層 → 一個 pp.，斷層用逗號 → pp. 1~5, 8~10
   - 題號：一個 `#`，斷層同樣逗號 → `#31~50` 或 `#1, 3~5`
   - 1.0 寫成 1

## 組字串

- 同一套餐：套餐名＋空格＋頁碼段；同套餐還有題號，再逗號接上。例：`vBK-2 pp. 6~10, 221~230` ／ `WORD p. 1, #31~50`
- 不同套餐：全形分號。例：`vBK-2 pp. 1~5, 8~10；WORD p. 1, #31~50`

## 大腦／手腳

- 大腦（出作業 UI）：combinePackRangeLabel 算小標題，寫進錄音／考試標題與 material_range。
- 手腳（學生頁、之後若接表頭 Ranges）：只讀這串字，不准再算、再融、再削。

Snapshot 每一列仍帶自己的起迄（material_refs 的 range_spec）。小標題是顯示用的全域範圍字串，不是把多列 refs 消成一列。

## 驗收

- 套餐 vBK-2、兩段 6～10 與 221～230 → `vBK-2 pp. 6~10, 221~230`（不是活頁別名）
- 同一套餐 1～2 與 3 → 套餐名 pp. 1~3
- 同一套餐 1～5 與 8～10 → 套餐名 pp. 1~5, 8~10
- 兩份套餐 → 套餐名 pp. …；另一套餐名 pp. …
- 獨立考試兩個區塊同一套餐相連起迄 → 同一串，不准再寫成 套餐名 pp. 1~2；套餐名 p. 3
- 區段欄仍顯示活頁別名
- 不准出現「pp. 1~2 ; p. 3」、中括號包 pp.、只修例子另一套
