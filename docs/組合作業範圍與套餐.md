## 來源類型（三種套餐同一層）

2026-08-29 老師定案；2026-09-01 正名：Excel 與 JSON 是同一類，不是兩種套餐。套餐的**來源**同一層，不是旁支：

```
Excel/JSON（同一類；副檔名不同不是套餐類型）
PDF（不是附件、不是「還沒套用所以不算教材」）
目錄（老師提供範圍，系統收集成書；不是從夾裡的檔自動產卡）
```

做成試卷＝套用**試卷範本**。來源類型相同 ≠ 同一份套餐。

產生在同一頁（教材範本管理）分三區，不准合併成一個「新增套餐」：

```
Excel/JSON：套用擷取範本 → 產出 meta → 再套用試卷範本 → 這份套餐的試卷。區塊＝套用／設計範本。
PDF：不走擷取、不產 meta。套用的是試卷範本（試卷範本不同＝不同套餐）。獨立區塊＝勾夾裡 PDF＋套用。
目錄：選夾後＋新增空卡。出作業填主單元／次單元／標題／大題／次題／小題才收集。另一獨立區塊。
教材區：一個窗口一個夾，只顯示已有卡。
```

PDF 的試卷範本有兩種：

1. **左到右、上到下**（預設）：解答與空格依這個順序配。
2. **老師定位**：老師依解答順序點空格，學生只填字。

解析答案後要對帳：解答的 Quiz 組跟題目 PDF 掃到的 Quiz 組是否對得上。對不上 → 紅色警示；有問題的那一組，老師決定要不要改用「老師定位」。禁止因為某一組沒解析到就當成沒有、從畫面拿掉。解答有大題標頭＝這一組存在；沒有「1.」題號不准把該組整段丟掉（依出現順序收成第 1、2、3… 題）。編號 1…N 中間缺號＝缺的那一組仍要列出。

`detectSectionPageRanges` 是掃大題標題頁碼的方法，不是套餐定義。不准把任何一種寫死成「PDF 套餐＝自動找大題」。

## 套餐是什麼

Excel／JSON 這條（現行、未改、未廢）：

```
有活頁、有擷取範本、有試卷範本 → 這三個對上的就是這一份套餐。
同一本活頁／同一份 JSON 可以有多份套餐（試卷範本不同＝不同套餐）。
```

PDF 這條（同一把鑰匙，只是沒有擷取／meta）：

```
有 PDF 來源檔、有試卷範本 → 這兩個對上的就是這一份套餐。
同一份 PDF 可以套不同試卷範本 → 不同套餐。
不是「都是 PDF 考卷」就同一類套餐。
```

```
is_group＝false → 一份套餐對一本活頁／一個來源檔。
is_group＝true → 見下一節「群組／總套餐」。
```

舊句「套餐＝資料夾 + Excel + 擷取」已作廢。那把鑰匙會把不同活頁／不同試卷收成一筆。  
也禁止把 PDF 當資料夾裡的附屬檔名清單，不當套餐來源。

## 群組／總套餐（套用時勾選 is_group｜不是自動成群）

Excel／JSON：處理（套用擷取／試卷）時勾選「群組」。  
PDF：套用試卷範本時同樣勾選「群組」。沒勾＝false，不准猜成群組。

勾了群組，才把**這次勾選、同一資料夾、同一種試卷範本**的來源收成一顆。不是「同一資料夾」或「都是 PDF」就自動成群。不准跨資料夾勾群組。

```
同性質、內容不同 → 套用時勾「群組」→ 收成一顆。沒勾就各一份。
A、B、C 各自是一份（活頁／來源）；勾了群組 → 出現時是一顆「總套餐」
  （教材區／改檔名／出作業／出題同一張卡、同一個已存套餐名）。
選了總套餐之後，再選 A／B／C 哪一份（區段下拉；這份總套餐自己的成員，一次選一本）。
```

驗收樣本（不是 if 條件）：

```
同一份 JSON，套兩種試卷範本 → 兩份套餐。
GEPT-2 整句翻譯 vs 句子填空：兩種模式 → 兩顆總套餐。
Azar-2_5th_test 的 01／02／03／04：同一資料夾、四個 PDF、套同一種試卷範本，
  **套用時有勾群組** → 一顆總套餐底下的四份（每一份 PDF 自己一份 txt）。
  套用時沒勾群組 → 各一份套餐。
  若之後另套另一種 PDF 試卷範本 → 另一顆套餐。
```

禁止：因為都是 PDF 考卷就收成一顆。  
禁止：跨資料夾勾群組。  
禁止：把唯一那種 PDF 試卷範本寫死成套餐定義。  
禁止：以為群組是新功能、另寫一套 PDF 專用結合。  
禁止：把「列出雲端檔名」當成套餐。配對／上傳可以看到四個 PDF 檔；出作業／教材區卡片仍是已套用的套餐（套用時有勾群組才一顆）。  
禁止：夾裡還沒建套餐就把四個檔各當一份套餐塞進下拉。教材夾有檔＝這個夾是教材，不是「每個檔＝一份套餐」。

```
is_group＝true
  → 結合顯示成一顆（教材區／改檔名／出作業／出題同一張卡）
  → 同資料夾＋擷取＋來源、沒連活頁的空殼列併進這張（Excel／JSON 這條）
  → 套餐名＝這張群組卡「Excel/JSON 套餐」已存的 label
  → 選完套餐後，A／B／C 走「區段」下拉（PDF：這份套餐自己的來源）
is_group＝false
  → 一本活頁／一個來源一份套餐，下拉各列各自己的已存套餐名
  → 範圍表自動列出這份套餐的活頁，各列各選頁
```

PDF 套餐的預設名、資料表欄位怎麼長、第二種以後的 PDF 試卷範本長什麼：未再同意不准自發明。Excel／JSON 套餐程式不准為了 PDF 去改。

## 組合面板（出作業「組合（套餐、範圍、選題）」）

只准一份：`TimelineTemplates.renderRangePackHtml`（`FeatureTimeline.renderRangePackHtml` 轉呼）。  
組合層、獨立錄音、獨立考試、獨立 PDF 考都呼叫這份。不准再各寫一張範圍表。

一個組合層窗口。第一層選套餐；同一套餐要另一段範圍就「增加區段」；要另一份套餐就「增加套餐」。

### 套餐列

| 畫面 | 存什麼 | 規則 |
|---|---|---|
| 套餐下拉 | `pack_rows[].combo_id`、`combo_label` | 列上節已指派套餐。`__manual__`＝手動輸入教材。 |
| ＋ 增加套餐 | 新一塊 `combo_id` | 這塊只帶這份套餐自己的活頁。 |
| 刪（區段／套餐） | 刪該列／該塊 | 只刪這筆。 |

組標題＝套餐名。組標題空白時帶入已選套餐名。

### 範圍表（十二欄，出作業與考試同一把 grid）

| 欄 | 存什麼 | 規則 |
|---|---|---|

| 基準 | `range_type`：`page` 或 `qnum` | 有頁碼或題號才進標題匣。 |
| 起 | `start` | 有起、有迄才進標題。 |
| 迄 | `end` | 有起、有迄才進標題。 |
| 每頁行數 | `lines_per_page` | 跟活頁總題數算可用題。見 `docs/活頁總題數與可用題.md`。 |
| 難度 | `difficulty` | 這一列自己的。 |
| 必考# | `include_nums` | 這一列自己的。 |
| 排除# | `exclude_nums` | 這一列自己的。 |
| 題數 | `count` | 這一列要抽幾題。 |
| 可用題 | 綠字，現算不另存 | 活頁 `available_count`＋每頁行數＋起迄。 |
| 顯示% | 現算 | 有題數、有可用題 → 題數／可用題。 |
| 刪 | 刪這一列 | |

區段考題數＝這一份套餐塊裡各列「題數」加總（選用為考題的數），寫在「增加區段」同一行最右邊。左邊是「亂序」（預設打勾；打勾＝這份套餐抽出的題目打亂順序）。  
套餐總題數＝這一層組合裡所有套餐區段考題數的加總，寫在「增加套餐」同一行最右邊。  
獨立考試底部「總計考題」＝套餐總題數，同一把尺。不准改加 exam_job 舊區段。  
加的是題數欄，不是可用題。可用題綠字仍是這本活頁 available_count＋每頁行數＋起迄。

表格總寬對齊套餐下拉（面板 100%）。欄寬同一把 grid，出作業與考試共用。

## 學生文稿

擷取範本「學生文稿 特殊排版」老師寫什麼就套什麼。

老師給過的公式原文（一個字都不准改）：

```
<page title>vBK_name&" - "&page
<blank>
<data>item_no&". "&pos&"  "&pre&" "&answer_en&"     "&display_zh
```

有這三行標記 → 只套公式原文。  
格子是空的 → 編輯框空。

## 驗收

1. 出作業套餐下拉：這個班已指派的每一份套餐，文字是教材區已存套餐名（例如 `GEPT-2 整句翻譯`）。
2. is_group＝true → 結合顯示成一顆總套餐；選完後 A／B／C 在區段。
3. 同一來源（JSON 或 PDF）套不同試卷範本 → 不同套餐，不是因為來源類型相同就收成一顆。
4. GEPT-2 整句翻譯與句子填空是兩顆（兩種模式）。
5. 選套餐後區段列出這份自己的活頁；H、I 各一列，各自起迄。
6. 起 1 迄 2、每頁 10、兩列 → 可用題各 20、塊內加總 40。
7. 組標題空白時帶入套餐名；小標題是表名＋pp./#。
8. 更新內容後學生文稿＝上面三行公式現算（頁標題是 `vBK_name - page`，下面每一題）。
