# 活頁總題數與可用題

2026-08-22 再定案。這套很早以前就定過，後來綠字改去現讀 Drive／複習目錄，可用題又變 0。程式雷區：`.cursor/rules/sheet-available-count-invariant.mdc`。

## 為什麼要記在活頁上

套餐列本身沒有題數。出作業若每次現讀 `.meta.json`，讀不到或篩錯就是 0。  
總題數是這本活頁的基本資料，產生 meta 時就已經有（產出幾列、含結尾行）。

## 寫在哪、何時更新

- 表：`material_sheets.available_count`（一本活頁一個數字）
- 何時寫：教材範本管理「產生上傳」成功；進老師頁一次補齊所有尚無總題數的舊活頁（讀現有 Drive `.meta.json` 最後 item_no）
- 套餐不另存總和。畫面 A～Z 合併只是顯示／套公式，數字仍跟每一本走
- 舊活頁不必從 Excel 重跑，也不准等出作業一列一列按「讀取可用題數」。不准用複習目錄補

## 範圍內可用題怎麼算

除最後一頁外，每一頁一定滿行。頁碼從這本第 1 頁起算。

例：總題 94、每頁 20 行

| 範圍 | 可用題 |
|------|--------|
| 頁 3～4 | 40 |
| 頁 5 | 14 |
| 題號 1～82 | 82 |

公式在 `020_js_core/sheet-range-bounds.js`。範圍卡與考試同一把。

## 超出範圍

不要顯示 0 假裝沒題。用 `ModalOverlay` 告知最後一頁／最後題號，並自動改起迄：

- 只有迄超出：迄改最後一頁（基準頁碼）或最後題號（基準題號）
- 起也超出、頁碼：起迄都改最後一頁
- 起也超出、題號：起改最後一頁的第一題，迄改最後題號

## 跟「更新目錄」「讀取可用題數」的關係

- 更新教材目錄＝學生練習專區快照，不是出作業綠字
- 進老師頁會自動補齊尚無總題數的活頁；「讀取可用題數」不是補齊的正式做法
- 產生線上卷仍讀 `.meta.json` 抽實際題目
