# 班級設定／資源／訊息模板：派發與老師預設組合（討論整理）

> 整理自 2026-07-27～28 對話。僅本地規格備忘，不上傳。

## 1. 核心共識

老師需要的不是「每一班重複點過一模一樣的設定」，而是：

1. **先組好自己喜歡的功能組合**（預設）
2. **一鍵套用到名下所有班級（班群）**
3. **單一班級仍可覆寫**（例外調整）

這與資源「建制並派發」的產品邏輯相同：  
**預設／母體 → 派發範圍 → 單點覆寫**。

## 2. 三層範圍（統一語意）

| 層級 | 語意 | 典型用途 |
|------|------|----------|
| **全域** | 全校／全系統 | 官方預設、機構級素材或模板（風險高，需審核） |
| **班群** | 該老師名下所有班（含未來新班較理想） | 老師自己的預設組合、個人資源／模板 |
| **班級** | 單一班級 | 本班例外、細調 |

說明：

- 側欄「班群管理」是**班級主檔／本班設定入口**，不是資源 `scope` 名稱本身。
- 「班群」在派發語意上 ≈ **老師預設／老師範圍**；資料上可對應 `scope: teacher`（或老師預設組合），讀取時依該班 staff／主老師解析，新班才不必逐班複製。

## 3. 資源（Drive／連結）— 已朝此方向重構

- 獨立類型／入口：
  - **全域資料夾**：系統設定的 Drive 最頂層（起點）
  - **老師個人資料夾**：`_Teachers/{email前綴}_{uid後4}` 最頂層（起點）
- 最頂層是**瀏覽起點**，不是派發終點。
- 選夾流程應為：進最頂層 → 進入 `00`／`01` 等 → **選檔案**寫入網址（檔案才是派發目標）。
- 個人 Drive 綁定應寫入**老師工作區根目錄**，避免誤存成 `00`／`01`。

## 4. 訊息模板 — 可派發，但不是「資源」

### 4.1 為什麼不算資源

| | 資源 | 訊息模板 |
|--|------|----------|
| 本質 | 可開啟的連結／檔案 | 欄位編排與文案結構 |
| 消費 | 點開／下載 | 渲染提醒圖／學生訊息 |
| 資料 | url、type、icon | layout JSON、欄位與位置 |

結論：**同類「派發語意」，不同類「東西」**。不要塞進 `resources` 表，也不走「選 Drive 檔」流程。

### 4.2 建議的模板種類（討論中）

- 提醒：作業補交／作業提交 — **家長**
- 提醒：作業補交／作業提交 — **學生**
- 訊息：作業補交／作業提交 — **學生**

### 4.3 建議資料與入口

- 獨立實體（例如 `message_templates`）：`kind`、`layout`、`owner_id`、`scope`（global／teacher／class）、`target_class_id`
- 解析優先序：班級指定 → 班群（老師）→ 全域 → 系統預設
- **建制並派發（模板庫）**：與「資源管理」**同級**（側欄全域管理區，或同頁分頁）
- **本班採用／微調**：留在班級主檔設定（現有「開啟欄位編排」可演進為套用已派發模板）

### 4.4 全域風險（必須註記）

老師（或任意者）往**全域**投放模板／資源，可能造成全校文案／版型被污染、難追溯。

**以後必須建立篩選或審核機制**（例如：全域僅 admin、或 `pending_review` 白名單）。  
現階段若做 UI，應在全域選項旁註明此限制為硬需求，非正式上線條件。

## 5. 班級主檔設定 — 一班一設沒效率（附圖討論）

現況合理之處：每班可獨立設定（名單顯示、遲交預設、提醒欄位版面、AI 批改等）。

痛點：同一老師多班時，相同偏好要**一班一班手動改**。

期望：

- 老師組好「課程功能組合」
- **一鍵套用到班群（名下全部班）**
- 個別班級仍可再改

對應關係：

| 層級 | 角色 |
|------|------|
| 老師預設組合（班群） | 一鍵套用；新建班亦可自動帶入（理想） |
| 班級覆寫 | 單一班例外（現有班級主檔設定） |
| 全校預設（可選） | 老師未設組合時的保底 |

「組合」可涵蓋附圖區塊，例如：

- 名單顯示模式  
- 班級遲交預設規則  
- 提醒訊息欄位版面（或綁定某訊息模板）  
- AI 批改成績設定（含覆寫角色）  

實作前需再定：套用時「整包覆寫」還是「只填空白」；新建班是否自動帶入。

## 6. 產品結構建議（入口怎麼擺）

```
全域管理
├── 資源管理          ← Drive／連結：建制並派發（全域／班群／班級）
├── 訊息模板（建議）  ← layout 模板庫：建制並派發（同上語意，獨立資料）
├── 我的班級預設（建議）← 老師功能「組合」＋一鍵套用名下所有班
└── 班群管理
    └── 各班「班級主檔設定」← 本班覆寫／細調（含欄位編排採用結果）
```

## 7. 與實作狀態的落差（備忘）

- 資源三層 scope、老師／全域 Drive 入口、選檔導覽：對話中已朝此方向改。
- 訊息模板獨立庫＋派發：討論定案方向，**尚未**當完整功能落地。
- 老師「班級功能組合」一鍵套班群：討論定案方向，**尚未**實作。
- 全域審核／篩選：已列為後續硬需求，須在規格與 UI 註記。

## 8. 一句話總結

**資源、訊息模板、班級功能設定，都走「老師可組預設 → 派到班群／班級（全域另議且要審）→ 單班可改」；不要把模板當成資源檔，也不要只靠班群管理裡逐班點設定。**
